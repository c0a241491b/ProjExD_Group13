# 工科クエスト

## 実行環境の必要条件
* python >= 3.10
* pygame >= 2.1

## ゲームの概要
* 主人公「こうかとん」となり、次々と現れる「課題」やボスの「悪の組織」を倒すRPGである。

## ゲームの遊び方
* 矢印キーでマップを移動し、キャンパス奥地のボスを目指す。
* 戦闘中はキー入力（A：こうげき、M：魔法攻撃、H：回復魔法）でコマンドを決定し敵を倒す。
* プレイヤーのHPが0になったらゲームオーバー、ボスを倒すとゲームクリアである。

## ゲームの実装
### 共通基本機能
* 背景画像と主人公キャラクターの描画
* 戦闘システム

* フィールドマップ移動時のランダムエンカウント機能。

* キャンパスマップ特定座標到達時のボス戦イベント発生機能。

* A,H,M,1,2,3キー押下による戦闘処理と、敵味方HP,MPの管理、勝利判定。

### 分担追加機能
* 戦闘担当：江澤、田代、福村
    * コードのベース作成担当：江澤
    * 計算処理担当：福村
    * 遷移演出担当：田代

* マップ担当：矢部、辻

    * 最初の村、キャンパスフィールド担当：辻
    * キャラクターの描画、外フィールド担当：矢部

### 戦闘
- マップ移動中の遭遇（確率で発生）：通常敵とボスが存在する。
- 表示：敵は画面中央に描画され、画面下部に「敵HP」「プレイヤーHP」「回復残り」が表示される。

#### 操作
- A：こうげきをする。
- H：回復魔法をする。
- M：魔法攻撃をする。
- 1：回復道具を使用する。(3回まで使用可)
- 2：攻撃力アップのアイテムを使用する。(1回まで使用可)
- 3：防御力アップのアイテムを使用する。(1回まで使用可)
- R：GAME OVER画面でリトライをする。（村に戻りHP回復）
- ESC：ゲームを終了する。

- 戦闘：ターン制バトル。プレイヤーが操作選択をするとこうかとん、敵の戦闘が始まる。
- ボス戦：キャンパス奥で発生し、敵HPが高く強力な攻撃を行う。
- GAME OVER：プレイヤーのHPが0になったらGAME OVER画面を表示します


### 追加・改良点（本実装で追加/調整した主要機能）
- 戦闘メッセージ用の小さいフォントを追加し、戦闘時のメッセージ表示とHUDを小さめの文字で表示するようにした（行間も詰めて見やすく調整）。
- アイテム機能：`potion`（回復薬）、`atk`（攻撃UP）、`def`（防御UP）を実装。キー1/2/3で使用できる。
- バフ（ATK/DEF）：バフの残りターン管理（`atk_buff_turns` / `def_buff_turns`）と倍率適用（`atk_multiplier` / `def_multiplier`）。
※バフとは、自分の攻撃力や移動速度（ただし今回は実装していない）などのステータスが上がり、有利な状態が発生することである。
- マップ遷移とランダム遭遇：マップ端での遷移（村→フィールド→キャンパス）と、フィールド移動時に低確率でエンカウントする。
- 日本語フォント検出機能：`get_japanese_font(size)` でOS上の日本語フォントを優先して取得し、フォントが見つからない場合は代替フォントを使用する。
- 終了／リスタート処理：`GAME OVER` と `R` によるリトライ（村に戻りHP回復）、`ESC` で終了が可能。
* 魔法や回復使用時にMP残量を確認し、不足時はターンを消費せず行動をキャンセルする機能。
* レベルアップ機能：経験値取得によりレベルが上昇した際、ステータス上限の増加とHP・MPの全回復を行う機能。
* 外のフィールドシーンから戦闘シーンに切り替わるときに遷移演出を実施。
* こうかとんが敵にダメージを与えるときに敵が点滅する演出を実施。

### メモ
* 右に向かうとマップが切り替わる。奥地へ向かいゲームを進める。
* 外フィールドの敵を倒してしっかりレベルを上げ（課題に取り組み）、最後のボス（期末試験）を倒そう。
